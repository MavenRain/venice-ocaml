# M32 response decryption

Base: `1b48474`, the committed M31 probe and synthetic replay slice.

`Session.Stream(T).run session body consume` uses the existing effect-based
stream cursor and body-release bracket. The decoder authenticates every
nonempty `content` and `reasoning_content` frame before yielding its chunk.
A failed field rejects the entire chunk, including other fields already
decrypted locally. There is no plaintext fallback. Empty and null content and
reasoning_content fields are metadata; a null delta object or a null choices
member rejects. Any string role value is accepted; unsupported delta fields,
including tool calls, reject.

Frames are bounded before hex decoding, have a 93-byte minimum, and contain
an uncompressed SEC1 public key, a 12-byte nonce, ciphertext and a final
16-byte tag. Each frame derives its own key from the session scalar and the
frame public key, using the existing ECDH/HKDF schedule and empty GCM AAD.
The maximum plaintext size is 2,000,000 bytes. Decoder errors do not include
payload contents. 2,000,000 bytes is the decoder cap. `Session.Stream.run`
reaches it only when the caller raises `?max_line_bytes` above about 4,000,400,
because the Ssex line default is 1,048,576.

The pure decoder state retains the expected route model and first chunk's
id/created values. M31's synthetic terminal event omits object and created;
subsequent chunks inherit those fields when absent. Explicit changes to id,
model or created reject. The first chunk still needs the ordinary chunk
identity. No shared JSON or chunk-parser checks were relaxed.

The stream requires DONE by default and retains the existing bounded
post-DONE drain, early-cut outcome, close-error precedence and dead-cursor
behavior. `Session.Stream.run` takes `?closing`, so a caller can select
`Allow_eof`. Complete has the ordinary stream framing meaning; callers still
inspect collection results and the returned outcome. The decoder state is
local to each run.

## Limits

No live network request was made. M31's wire shape is still synthetic and
live interoperability is unconfirmed. The default closing policy is
Require_done because the synthetic M31 fixture terminates with [DONE]. The
live E2EE terminator stays unconfirmed, so a caller that meets a clean EOF
must pass `?closing:Allow_eof`. GCM authentication alone does not prove
that the peer is the attested signer: anybody knowing the client's public key
can construct a frame. Transcript receipt verification, ordering and replay
protection remain M33 work. An active network attacker can replace a content
or reasoning frame with `""` or `null`, or drop a whole chunk. The decoder
accepts a blanked field as metadata, so deletion and truncation stay
undetectable until M33 receipt verification. Routing and completion metadata
are unverified.
Chunks already consumed remain provisional and cannot be retracted after a
later failure. This slice does not claim constant-time scalar arithmetic,
secret zeroization, whole-response authentication, or GPU admission.
